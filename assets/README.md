# Illustrated game assets

Generated with the built-in image generation tool, then copied into this repository. Original PNGs and alpha channels are preserved. No API key or external runtime service is required to play.

- `strip-panorama.png`: 2172 × 724 painted skyline. Shared atmospheric backdrop; zone-specific casino names are drawn in the foreground.
- `tourist-walk.png`: 1536 × 1024 transparent six-frame walking sheet, 3 columns × 2 rows.
- `strip-characters.png`: 1774 × 887 transparent cast atlas, 4 columns × 2 rows. The pedestrian poses use subtle motion; they are not full walk cycles.

Sprite source rectangles are recorded in `ART` in `vegas-art.js`. Runtime drawing crops the atlas without modifying the PNG files. Missing images use the existing procedural character/skyline fallback.

The nightlife scene atlas is `vegas-detours.png` (1536 × 1024). Its complete prompt and panel order are in `vegas-detours-prompt.md`.

## Generation prompts

### strip-panorama.png

Use case: stylized-concept. Asset type: production background panorama for a 2D side-scrolling Las Vegas arcade game. Create a very wide 3:1 landscape illustration, ideally 3072x1024. Premium hand-painted cartoon game art, rich architectural detail, softly textured gouache with clean strong shapes, atmospheric blue-violet dusk, gold and coral marquee lights with teal highlights. Camera looks straight across the Strip, side-on elevation, NOT looking down a road, NO vanishing-point road. Compose continuous hotel skyline: sweeping gold Mandalay-inspired resort towers, black Luxor pyramid with white sky beam, playful castle turrets, layered art-deco casino towers and distant mountains. Upper 35% mostly deep navy indigo sky with delicate haze and a few stars, no big moon. Lower half rich overlapping architecture and warm illuminated casino facades. Bottom edge buildings end on a single perfectly horizontal baseline; NO sidewalk or road in the image because the game will draw that separately. No people, no cars, no foreground palms, no UI, no logos, no letters or text. Both far left and far right edges should have similarly dark small distant buildings and sky for gentle crossfaded tiling. Beautiful sophisticated illustrated travel-poster meets animated adventure game, cohesive palette, dramatic depth, detailed windows and materials, avoid generic flat rectangles and avoid photorealism. Save the generated output as an asset.
